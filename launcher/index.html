SPX EXTENSION HUB · MIGRAÇÃO OBRIGATÓRIA

O prazo de migração terminou.

O SPX Extension Hub / SPX Extension Loader foi descontinuado em 31/10/2026. As ferramentas Dock Flow, Assistente de AutoAdd e Assistente de Devoluções não estão mais disponíveis nesta versão.

Para continuar utilizando as ferramentas, instale exclusivamente o TRILHO pela Chrome Web Store. Não é necessário instalar arquivos ZIP ou atualizar o loader antigo.
Instalar TRILHO na Chrome Web Store
  1. Instale o TRILHO pelo botão acima.
  2. Remova o SPX Extension Loader antigo em chrome://extensions. Não remova o novo TRILHO.
  3. Atualize as abas do SPX para evitar scripts duplicados.

Não mantenha as duas extensões ativadas simultaneamente. Caso a instalação seja administrada pela empresa, solicite a remoção ao responsável.
